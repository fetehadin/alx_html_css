🎧 Headphones Landing Page

Welcome to the Headphones Landing Page Project, built entirely from scratch using only HTML and CSS—without any frameworks, libraries, or JavaScript (except where required). This project was completed as part of the ALX Frontend Program, with a strong focus on mastering web design fundamentals, accessibility, and responsive layout.

📌 Project Description
The goal of this project is to recreate a pixel-perfect landing page design from a Figma file provided by designer Nicolas Philippot. The challenge was to implement the entire design using semantic HTML and modular CSS, ensuring accessibility, responsiveness, and fidelity to the original design.

    💡 Note: This page dynamically adapts to smaller screens (mobile view at <=480px) and applies interactivity and visual transitions in later tasks.

	
🧱 Features

    Responsive layout (mobile-first design)

    CSS variables for design consistency

    Icon fonts via custom icon pack

    Fully accessible and semantic HTML

    Clean UI animations and transitions

    Mobile hamburger menu via JavaScript

🧠 What I Learned

    Structuring HTML for large-scale projects

    Creating reusable CSS components

    Using Flexbox and media queries for responsiveness

    Designing without relying on CSS frameworks

    Advanced DOM-free interactivity via CSS (hover states, transitions)

    Implementing design systems from Figma mockups



💻 Tech Stack
Technology	Purpose
HTML5	Semantic page structure
CSS3	Styling, animations, responsive design
Figma	Source for pixel-perfect UI implementation
Font Icons	Visual iconography with custom font packs
JavaScript	Only in Task 8 – for mobile hamburger menu
🎨 Key Design Guidelines

    Max content width: 1000px, centered on screen

    Mobile breakpoint: 480px

    Hover color (links/buttons): #FF6565

    Button active state: opacity: 0.9

    Consistent padding, margins & font sizes as per Figma mockup


✅ Accessibility & Best Practices

    Alt text for all images

    Use of aria-label and semantic tags

    Responsive font sizing with rem

    Mobile-first approach with media queries

    CSS variables for easier theme control
